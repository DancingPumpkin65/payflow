# Payflow

An offline Android work-day, income, and expense tracker.

Payflow keeps work days, rate history, and expenses on the device. It has no account, backend, or network dependency.

- Mark work days, track historical pay rates, and record shop revenue separately.
- Categorize Personal/Shop expenses with built-in or custom spending categories.
- Review monthly charts or analyze a 7/15/90-day or custom period.
- Set monthly savings targets using net income or logged savings transfers.
- Explore yearly work activity and tap dates to open their calendar details.
- Create timed events with local notification reminders; Android notification
  and precise-alarm permissions are requested when needed.

[Feature behavior and validation](docs/insights-savings-reminders.md).

## Run locally

Open the project in Android Studio, install the Android 35 SDK when prompted, and run the `app` configuration on an Android 8.0+ device. The app does not request network permission.
